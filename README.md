# СПОРТ.КРУГ — прототип спортивного портала

## Запуск
Откройте index.html в современном браузере. Установка пакетов и сборка не нужны.
Файл sport-portal.html, поставляемый отдельно, — та же версия одним файлом.

## Файлы
- index.html — каркас страницы и окна.
- styles.css — оформление, адаптация, переменные светлой и тёмной тем.
- app.js — каталог, демонстрационные материалы и логика интерфейса.

Код написан на обычном JavaScript без React и сторонних библиотек: проще запустить и изменить.

## Что работает
Светлая и тёмная темы; каталог из 165 дисциплин и направлений в 10 категориях
с подкатегориями; поиск (введите запрос и нажмите Enter); статьи и сохранение;
регистрация и вход; редактирование профиля; календарь с переключением месяцев;
локальная запись на события и расписание; демонстрационный чат; витрина наград.
Каталог расширяемый, не исчерпывающий и не официальный реестр.

## Демо-вход
Логин: sport
Пароль: demo2026

Регистрация создаёт один тестовый аккаунт в памяти вкладки. Профиль, пароль
и переписка не сохраняются на диск. Перезагрузка удаляет аккаунт и чат.
Используйте только вымышленные персональные данные и отдельный тестовый пароль.
Тема, номера избранных материалов и записей на события сохраняются в localStorage.
Данные не разделены между аккаунтами: это демонстрация интерфейса одного браузера.
Удалить локальные данные можно через «Конфиденциальность» внизу страницы.

## Что не подключено
- Настоящие VK ID и Госуслуги (ЕСИА): кнопки объясняют необходимость интеграции,
  но не имитируют успешную внешнюю авторизацию.
- Серверная регистрация, защищённые сессии, база пользователей и восстановление пароля.
- Доставка сообщений, управление реальными мероприятиями, подтверждение наград.
- Реальные новости и спортивные клубы: весь контент демонстрационный.

## Перед публичным запуском
Нужны сервер и база данных, HTTPS, серверная валидация, хеширование паролей
(Argon2id или bcrypt), безопасные HttpOnly-сессии, защита от перебора и CSRF,
проверки прав доступа и изоляция данных пользователей. Для VK ID / ЕСИА
зарегистрируйте приложения и реализуйте авторизацию по требованиям провайдеров
с серверным обменом кода, проверкой state и PKCE там, где поддерживается.
Секреты приложений не должны попадать в клиентский код.

Текст политики — только шаблон. Нужны юридическая проверка, сведения об операторе,
корректные согласия, порядок удаления, сроки хранения и отдельная проработка
обработки данных несовершеннолетних с учётом применимых требований 152-ФЗ.

## Как расширить
В app.js: sports — категории и дисциплины; news — публикации; events — события;
menu — пункты меню. В styles.css: :root — светлая палитра,
:root[data-theme=dark] — тёмная. Для настоящих данных замените локальную
логику обработчиками запросов к защищённому серверу.
